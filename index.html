What is this?

malxchange is an open-source cryptocurrency exchange (Go microservices + Nuxt 3 frontend) deployed live for evaluation. It runs:

  • 5 Go microservices (api, exchange, market, wallet, admin-api) + PostgreSQL + Redpanda/Kafka
  • Real Litecoin and Bitcoin simnet nodes — deposits are mined on actual (test) blockchains
  • Markets: BTC/USDT, ETH/USDT, LTC/USDT, LTC/BTC
  • Full member flows: registration (email verification), login, deposits, trading, withdrawals
  • Admin panel with TOTP 2FA

Deployment Options

All-in-One VPS (~€4/mo)

Everything on a single 4GB VPS. Total stack uses ~1.1GB RAM. Cheapest and simplest — ideal for grading and demos.

Split with Free Tiers (~€0-4/mo)

Frontend → Vercel (free). Postgres → Neon/Supabase free tier. Kafka → Upstash free tier. Backend → €4 VPS. Managed DB backups, instant deploys.

100% Free (Demo)

Vercel + Neon/Supabase + Upstash + Render free tier. Works for demos; free tiers have limits and sleep.

Why did it look like "BIZZAN BETA"?

malxchange was ported from BIZZAN, an open-source exchange. The logo, orange-on-dark theme, and Chinese-priority fonts were inherited. We rebranded it to malxchange with modern typography.

Bugs found & fixed

  • Wallet simnet blindness — the chain client silently fell back to mainnet address decoding when ltcd errored, so simnet deposits never matched. Fixed by passing the operator-configured network as default.
  • Mailpit crash — MP_SMTP_AUTH_ACCEPT_ANY=1 kills mailpit v1.21; removed.
  • Trading page JS crash — MARKETS_PATH and ORDERS_PATH used but never declared.
  • Dead nav links — Exchange went to a 404; Member center pointed to a non-existent page.
  • BIZZAN rebrand — replaced logo images, fixed Chinese-aesthetic letter-spacing, switched to Inter font.

All fixes are on the fix/wallet-simnet-net-hint branch.
